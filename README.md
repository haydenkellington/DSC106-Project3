# A Landscape Before and After Natural Disasters

Six exploratory D3.js visualizations for DSC 106 Project 3. Open `index.html` in a browser and choose an event; the selector updates all six views. D3 and the MODIS images used by the prototypes are included locally. No server, plotting library, or API key is required for the starter views. The optional web fonts and external source links need an internet connection.

## Six designs

1. **Side by side:** a static baseline with a consistent extent for each event.
2. **Swipe:** drag the divider or use the range slider to compare dates.
3. **Fade:** change the opacity of the later image over the earlier image.
4. **Timeline:** choose or play through irregularly spaced observations.
5. **Color bands:** compare natural color against false color on a selected date.
6. **Linked zoom:** pan or zoom either panel and both follow. Buttons support zooming and resetting without a mouse wheel.

The six views are generated by `app.js`, laid out by `index.html` and `styles.css`, and use the local D3 library and images in `assets/`. The shell script `download_imagery.sh` records how to request the images again. To use GitHub Pages, commit this entire directory and enable Pages for the repository. Nothing has been deployed.

## MODIS imagery and event sources

Images were retrieved from NASA GIBS WMS as 960 × 640 JPEGs using EPSG:4326, November 4, 2026. For each event all dates and both color layers use the same geographic extent. In WMS 1.3.0, the BBOX order below is south, west, north, east. Layers: `MODIS_Terra_CorrectedReflectance_TrueColor` and `MODIS_Terra_CorrectedReflectance_Bands721`. [GIBS documentation](https://nasa-gibs.github.io/gibs-api-docs/access-basics/).

| Event | BBOX | Observation dates | NASA context |
| --- | --- | --- | --- |
| Dixie Fire and nearby fires, California, 2021 | 39.4, -122.0, 40.4, -120.5 | July 10, August 15, September 21, October 10 | [NASA: A Multi-Dimensional Fire Challenge](https://earthobservatory.nasa.gov/images/148913/a-multi-dimensional-fire-challenge) |
| Indus River floods, Pakistan, 2012 | 27.7, 68.5, 29.0, 70.45 | September 1, 8, 13, 20 | [NASA: Flooding in Pakistan](https://earthobservatory.nasa.gov/images/79171/flooding-in-pakistan) |
| Mount Kenya wildfire, Kenya, 2019 | -0.45, 36.65, 0.35, 37.85 | February 15, 20, 23, 27; March 15 | [NASA: Fire on Mount Kenya](https://earthobservatory.nasa.gov/images/144615/fire-on-mount-kenya) |

The default comparisons use July 10 and September 21 for California, September 1 and September 13 for Pakistan, and February 20 and March 15 for Kenya. NASA's Pakistan article identifies September 1 as an earlier comparison and September 13 as flooded conditions. September 13 is **during** flooding, not necessarily after it ended. NASA describes multiple fire scars in the September 21 California image; the view is not an isolated measurement of the Dixie Fire.

The selected dates are examples rather than a complete timeline. Cloud or smoke obscures portions of some scenes, especially Pakistan September 8 and California August 15. The Kenya March 5 request returned black/no coverage and was omitted. A later observation means after the event began; it does not establish when the event ended or was contained.

## Interpretation limits

GIBS provides rendered browse imagery here. This is useful for visual comparison, but it is not a numerical measurement of burn severity, flood depth, damage, land cover, or vegetation. Clouds, smoke, water, seasonal conditions, viewing and lighting can change appearances. A visible difference does not by itself prove cause or measure area affected. Do not compare colors across the two different band combinations as if they had the same meaning.

The false-color layer uses bands 7-2-1: shortwave infrared, near infrared, and red. Consult the linked NASA articles for context. NASA's Pakistan comparison uses visible and infrared imagery to improve contrast between water and land; the prototype's 7-2-1 layer is a GIBS rendering and is not asserted to use the identical processing as the article images.
